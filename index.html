Workflow Depth + Execution Fidelity — set before Stage 01

Two decisions that don't require brief context: Workflow Depth (how far to go) and Execution Fidelity (the quality bar). All other parameters — Creative Intensity, Generic Distance, Visual Risk, Reference Distance, Commercial Clarity — are set after Stage 01 when the category and audience are understood. Stage 02 Framework Selection and the Mini Traceability Check are never compressed regardless of mode.

● Full Mode

Flagship portfolio work, complex brand systems, high-stakes client projects, or when the goal is an outstanding authored prototype.

01 · Full brief extraction + category audit
02 · Framework selection + optional parallel test
03 · 3–5 concepts + NFRT + selection + amplification
04 · Full reference analysis + type + color + tension
05 · Full CDD + Traceability Check
05.5 · Style Reference + Hero + 1–2 concept sections
06–07 · Complete prototype, section by section
08 · Strategic critic + Cursor QA + protected list
○ Sprint Mode

Fast exploration, internal demo, early proof of concept, or when time is limited and speed matters more than depth.

01 · Core Transformation + Internal Problem + Exclusion Zone
02 · One selected framework — no parallel testing
03 · 3 concepts → one selected + amplified
04 · One typographic direction + one palette + one tension technique
05 · Mini CDD + Traceability Check
05.5 · Hero-only HTML proof
06–07 · 1–2 section prototype
08 · Critic focused on concept survival + first read + genericity
Stage 02 and the Mini Traceability Check are never compressed in Sprint Mode. These are where the concept is born or where it fails silently. Sprint Mode quality floor: The Sell the Idea Test is a hard stop. A failing concept does not go to Cursor regardless of time pressure. Sprint compresses depth — it does not lower the concept quality bar.

01 Claude 20 min
Brief Extraction + Category Audit
Know what everyone is doing — so you can deliberately refuse it
Input
Any source document — brief, product description, strategy notes, founder's memo, meeting summary
Skills used
extractor · semiotic-codes
  • Paste whatever document you have into the Brief Extraction prompt — it normalises any format into the same structured output
  • The three fields that cannot be left as [UNKNOWN]: Core Transformation, Internal Problem, Target Audience psychographics. These are the foundational inputs that enable any creative framework to operate — they are required regardless of which path Stage 02 takes.
  • Run the Category Audit immediately after — document what every competitor looks and sounds like before you try to be different from them
  • Write the Exclusion Zone as a specific directive: "This project will never use..." — vague principles are not enforceable
  • Identify the Whitespace Opportunity: what emotional territory does no competitor currently own?
Prompt — Brief Extraction
I'm going to paste a document below — it could be a brief, product description, strategy notes, or a meeting summary. Extract and structure it into a standardised project brief.

Do not add anything not in the source material. If a field is missing — mark it [UNKNOWN] and list it as an open question.

SOURCE DOCUMENT:
[paste your document here — any format, any length]

Extract and output:

What it actually does. One paragraph, plain language. No marketing copy.

Internal: the fear, doubt, or emotion beneath it.
Philosophical: the belief that this situation shouldn't be this way.

What are we building? [landing page / campaign / brand story / presentation]
Primary conversion goal: what should the user do?
Secondary goal: what should they feel or believe?

CONSTRAINTS
Visual or tonal restrictions. What this brand must never look or sound like.

DEFINITION OF DONE

Checkpoint — what you must have before moving to Stage 02
  • A completed brief with Core Transformation written as a human truth, not a product claim
  • Internal Problem is an emotion — not a feature request. "They want better analytics" is a feature request. "They fear losing credibility in a room of people smarter than them" is an emotion.
  • Target Audience psychographics filled — what they fear losing and what they aspire to become
  • A written Exclusion Zone with specific, testable prohibitions
  • A Whitespace Opportunity paragraph identifying unclaimed emotional territory
  • Zero unresolved [UNKNOWN] fields in the three critical areas above
How this becomes input for Stage 02

The brief does not dictate which creative framework Stage 02 uses — it supplies the raw material from which the most effective framework is selected. Framework Mapper reads the brief and recommends the best-fit path. Different briefs activate different approaches.

  • Core Transformation + Internal Problem → conceptual raw material for whichever framework Stage 02 applies: Ghost Extraction, Semiotic Code analysis, StoryKernel threat mapping, or Layered Metaphor blending
  • Exclusion Zone → constrains all framework outputs regardless of which method is chosen — prohibits directions that would produce category clichés
  • Whitespace Opportunity → signals the unclaimed emotional territory Stage 02 must navigate toward, whichever framework is applied
  • Category Audit (dominant / residual / emergent codes) → critical input for Semiotic Engineering path; directional input for all other paths
  • Target Audience psychographics → informs "Why Now" and Resonance evaluation in Stage 03 across all frameworks
⬡ Project Parameters — set after Stage 01, informed by the brief

Set these four parameters after completing Stage 01 — the brief tells you how saturated the category is, what the audience needs, and how much creative risk the whitespace supports. Narrative Depth follows automatically from framework selection. Visual Risk is set by Creative Intensity. Execution Fidelity is declared in Workflow Depth above. Four decisions, not seven.

Creative
Intensity
1 · Safe 2 · Distinct 3 · Editorial 4 · Radical 5 · Speculative

Controls how far the workflow moves from safe, familiar solutions. 1–2: commercial clarity preserved. 3: award-facing but usable — the default. 4–5: category-breaking, higher execution risk, reserved for briefs that explicitly call for it.

Generic
Distance
Low Medium High Extreme

Applied after the first visual proof exists — not during ideation. Extreme: no visual move is allowed unless traceable to the Core Tension. Applied at Stage 05.5 Sell the Idea Test and Stage 08 critic review.

Commercial
Clarity
Low · Portfolio first Medium · Balanced High · Conversion protected

Protects product clarity and conversion goals against experimental drift. High: choices that reduce comprehension are rejected at Stage 08 regardless of concept strength.

Reference
Distance
Near Category Adjacent Far Outside

Sets how far Stage 04 reference analysis reaches. Near: direct competitors. Adjacent: editorial, fashion, type culture. Far Outside: architecture, scientific visualization, industrial design — the category's own references pull toward dominant codes.

◈ Creative Director Signature — personal creative DNA

The difference between AI output and art director output is personal contamination: accumulated taste, current obsessions, known failures, irrational refusals. Fill these four fields honestly — not correctly. Vague answers produce generic contamination. These fields make the output specific to who is running this, not just to what the brief says.

1 · Current Obsession

What you can't stop thinking about right now — completely unrelated to this project. A specific film, building, album artwork, sport, restaurant, paper. Not a genre or category. One specific thing.

→ Becomes a mandatory reference in Stage 04a. Claude will explain its connection to Core Tension — especially if that connection isn't obvious.

2 · Personal Refusal

One thing you will not do on this project regardless of how appropriate it seems. Personal, irrational, possibly unjustifiable. Not from the brief — from your own experience with what you've seen fail.

→ Appended to Exclusion Zone. Cannot be overridden by brief logic or framework recommendations.

3 · Taste Temperature

What kind of work genuinely excites you right now. Not the correct answer — honest. It may contradict the brief. That tension is productive.

→ Informs Stage 03 concept selection and Stage 04 reference choices.

4 · Known Trap

The pattern you personally fall into. Something that looks good in your hands but you've learned leads to a weaker result. Not a weakness — a tendency.

→ Becomes a named check in Stage 08 Strategic Review. The critic looks for it explicitly.

Quality check — before proceeding

Two different creative directors running the same brief should produce two different Signature Blocks. If yours could belong to anyone — rewrite the fields that are still generic. See creative-director-signature.md for full protocol and Signature Summary template.

Input

Skills used

Critic rule The critic identifies one problem and proposes one specific fix. It does not rewrite from scratch. It does not suggest adding new elements. Improvement almost always means removing something — not replacing it with something else or compensating with additions.
Protected list Before any fixes, list what is working and must not change. Name at least three specific things. This protects the concept's strongest elements from being eroded by the refinement process. The more specific the protected list, the safer the review.
Judgment source Every critic judgment is made against the CDD — not against taste, trend, or the reviewer's preference. If the fix cannot be traced back to a specific CDD field, it is an opinion, not a correction.

Four rules
that protect
the concept.

01 ·

Ideation is open. Execution is closed.

Before the handoff: explore, diverge, challenge every direction. After the handoff: execute without questioning the concept. The tool that builds must not also decide what to build.

02 ·

The conceptual foundation must survive into the final file.

Whatever was built in Stage 02 — Ghost, Emergent Code, Existential Threat, or Blended Space — must be visible in the finished prototype. If you cannot trace it from the CDD to the live page, find exactly where it disappeared and fix only that.

03 ·

Every element earns its place through function.

Representational, Interactional, Compositional. An element that carries none of these is decoration. Decoration is noise. Noise dilutes the concept. Remove it before it dilutes everything else.

04 ·

Improve by removing, not by adding.

The impulse to add is commercial pressure dressed as creativity. When the critic finds a weakness, the answer is almost always to remove something — not to add a new element to compensate.
